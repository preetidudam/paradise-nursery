# Paradise Nursery Shopping Application

## Project Name

Paradise Nursery

## Description

Paradise Nursery is an online plant shopping application built using React and Redux.

The application allows users to:

- Browse different categories of houseplants
- View plant images, names, and prices
- Add plants to a shopping cart
- Increase or decrease plant quantities
- Remove plants from the cart
- View individual and total cart costs
- Continue shopping
- Proceed to checkout

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
- Vite

## Features

### Landing Page

The landing page displays the Paradise Nursery company name and a Get Started button.

### Product Listing

The application contains multiple categories of plants with multiple plants in each category.

### Shopping Cart

Users can add plants to their cart and manage quantities.

### Checkout

The checkout feature currently displays a Coming Soon message.
